**咖啡店扫码点单系统**  
**需求文档 + 设计文档**  
**版本：V1.0**  
**日期：2026年8月**  
**基于前期全部沟通要点整理**

---

### 1. 项目概述

**项目名称**：精品咖啡到店点单系统（H5 优先，后续迁移微信小程序）

**项目背景**  
个体户新开精品咖啡店，桌台少于20张，经营模式为堂食 + 自取。目前无流水，预算严格控制在3000元以内，不接受年费SaaS模式。已有初级云服务器，域名与备案处于准备阶段，曾接入微信小商店（认证仍有效），具备微信支付能力，有打印机，有固定技术人员可后期维护，店员可简单操作后台。

**核心目标**  

1. 顾客扫码快速点单、支付，降低人工点单错误与等待时间。
2. 支持可选桌台绑定，兼顾堂食与自取。
3. 沉淀基础经营数据（热销、时段、复购）。
4. 高度匹配精品咖啡品牌视觉，提升专业感。
5. 先上线H5可用，代码结构支持后续平滑迁移微信小程序。
6. 自托管、一次投入、长期可控成本。

**成功标准**  

- H5版本核心流程（扫码→点单→支付→打印→后台管理）稳定可用。  
- 首期成本控制在3000元以内（不含已有服务器与打印机）。  
- 技术人员可独立维护与简单迭代。  
- 视觉达到精品咖啡调性，无廉价感。

### 3. 用户角色

1. **顾客（C端）**
  扫码进入、浏览菜单、选择规格、下单支付、查看订单。
2. **店员/老板（B端）**
  管理商品、桌台、实时处理订单、查看基础统计、配置打印机。
3. **技术人员（运维）**
  服务器维护、功能迭代、数据备份、问题排查。

---

### 4. 功能需求

#### 4.1 用户端（H5，P0必须）

- 扫码进入：支持桌台码（自动绑定桌号）与门店码（无桌号，走自取）。
- 首页：品牌展示区 + 分类入口 + 热销推荐。
- 菜单：分类导航 + 商品列表 + 商品详情。
- 多规格选择：杯型、温度、甜度、小料（支持加价），中等复杂度。
- 购物车：加减数量、备注、实时计算总价。
- 确认订单：选择堂食（显示已绑定桌号）或自取、可选填手机号、备注。
- 支付：微信支付（H5），支持模拟支付开关方便测试。
- 订单：列表与详情，状态流转（待支付→已支付→制作中→已完成）。
- 个人中心：历史订单。

#### 4.2 商家后台（P0必须）

- 登录鉴权。
- 店铺设置：名称、Logo、营业时间、公告、堂食/自取开关。
- 分类管理、商品管理（上下架、排序、图片、多规格SKU）。
- 桌台管理：新增/编辑、状态、生成带参数二维码并支持下载。
- 订单管理：实时列表、接单、完成、取消/简单退款、触发打印。
- 打印机配置与测试打印（对接现有云打印机）。
- 数据统计：
  - 日/周/月销售额、订单量
  - 热销品排行（按销量/金额）
  - 按小时时段销售曲线
  - 简单复购统计（按手机号/openid去重）

#### 4.3 后续迭代（P1，上线后1–2个月）

- 简单会员（手机号绑定 + 消费记录）
- 订单自动打印优化 + 语音提醒
- 数据导出Excel
- 基础满减优惠券

#### 4.4 明确不做（第一期）

复杂营销活动、储值卡、分销、外卖配送对接、多门店、KDS厨显、排队取号等。

---

### 5. 非功能需求

- **性能**：菜单加载 <2秒，订单提交 <1秒；支持高峰同时在线约50人。
- **安全**：HTTPS、JWT鉴权、微信支付官方接口、防刷基础校验、数据自有。
- **兼容**：主流手机浏览器（H5）；代码预留微信小程序编译能力。
- **可维护**：结构清晰，技术人员可独立修改商品逻辑与统计。
- **数据**：全部存储于自有服务器（MySQL），支持备份。
- **品牌定制**：主题色、Logo、圆角、卡片样式全部可配置。

### 6. 系统架构

**总体架构**  
用户端（UniApp H5） ↔ 后端API ↔ MySQL + Redis  
商家后台（Vue3 或 UniApp H5/PC）  
云打印机（HTTP推送）  
微信支付

**技术选型建议**  

- 前端：UniApp（Vue3）——一套代码支持H5，后续直接编译微信小程序。  
- 后端：Spring Boot 3 + MyBatis-Plus（或 Node.js，按技术人员熟悉度最终确定）。  
- 数据库：MySQL 8  
- 缓存：Redis（菜单缓存）  
- 部署：现有云服务器 + Docker Compose + Nginx  
- 支付：微信支付  
- 打印：飞鹅 / 易联云等云打印API

**未来迁移微信小程序要点**  

- 支付、登录、二维码、合法域名需适配。  
- 代码已用条件编译与平台适配层，减少重写。

### 7. UI/UX 设计规范（精品咖啡路线）

**设计定位**  
干净、克制、品质感、温暖、产品优先。参考 % Arabica、Blue Bottle、国内优质独立咖啡馆点单体验。避免廉价促销红点与夸张动效。

**色彩**  

- 主色：`#3D2B1F`（深咖啡棕）  
- 辅助色：`#C4A484`（浅咖/燕麦）  
- 背景：`#F9F6F1`（米白）、`#FFFFFF`  
- 主文字：`#2C1810`  
- 次文字：`#6B5B4F`  
- 圆角：卡片12–16px，按钮8–12px  
- 阴影：极轻（0 2px 8px rgba(0,0,0,0.04)）

**布局与组件**  

- 首页：顶部简洁品牌区 → 分类 + 商品列表（推荐左侧分类 + 右侧列表或双列卡片）。  
- 商品卡片：大图优先（1:1或4:5），名称 + 价格 + 轻标签。  
- 规格选择：底部抽屉，圆角标签选项。  
- 购物车：底部常驻栏（数量 + 总价 + 去结算）。  
- 订单确认页：清晰区分堂食/自取，信息干净。  
- 后台：白底 + 浅灰数据卡片 + 克制表格，实时订单突出。  
- 动效：仅必要轻过渡，禁止夸张动画。

**文案语气**  
专业克制。按钮示例：「加入购物车」「确认下单」「立即支付」。

**品牌资产需求**  

- Logo（高清透明底）  
- 最终确认主色（默认使用上述色值）  
- 可选门店实拍图作为首页参考

### 8. 核心数据模型（概要）

- shop（店铺）  
- category（分类）  
- product + product_sku/spec（商品与多规格）  
- table_info（桌台）  
- user（用户，预留openid）  
- order + order_item（订单与明细）  
- 统计相关字段或视图（热销、时段、复购）
