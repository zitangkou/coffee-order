# 1. 项目概述

## 1.1 项目背景

建设一套属于单店精品咖啡店自己的数字化经营系统。

解决：

### 用户侧

- 排队点单体验差
- 人工点单效率低
- 用户无法沉淀

### 商家侧

- 缺少经营数据
- 不知道商品表现
- 缺少会员体系

---

# 1.2 项目目标

打造：

> 一个服务于独立精品咖啡店的轻量级数字经营平台。

核心能力：

```
扫码点单

↓

在线支付

↓

订单制作

↓

会员沉淀

↓

经营分析
```
