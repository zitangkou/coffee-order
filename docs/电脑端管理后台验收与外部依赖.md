# Coffee OS 电脑端管理后台验收与外部依赖

## 已完成的代码能力

- 独立 Vue 3 桌面后台、登录、强制改密、30 分钟闲置退出与多标签会话同步。
- 经营看板、异常提醒、订单轮询、筛选、状态流转、支付/退款/后台操作时间线与补打。
- 商品、分类、规格、图片、批量上下架/分类/售罄、顺序维护、临时售罄自动恢复。
- 桌台启停、单个/批量小程序码生成、下载和 A4 打印。
- 会员脱敏查询、消费指标、等级与最近订单。
- 营业、商品、品类、时段、退款分析及防公式注入 CSV 导出。
- 营销活动管理：满减、全场折扣、新客优惠、会员日；服务端重新计价并自动选择最优优惠。
- 员工账号、角色隔离、审计日志、系统状态、门店设置和微信能力就绪度。
- 订单状态日志、生产 MySQL migration、本地 SQLite 同步与完整发布门禁。
- 独立非 root Nginx 镜像、回环端口、管理子域名网关、CSP、安全头和健康检查。

## 外部条件就绪后的执行清单

以下工作无法由仓库代码代替完成，但对应配置、检查入口和失败提示均已准备：

1. 为 `admin.nagacoffee.site` 配置 DNS，并申请/续期有效 TLS 证书。
2. 将 `deploy/nginx.admin.gateway.conf.example` 安装到宿主机 Nginx，确认只反代 `127.0.0.1:8081`。
3. 在服务器运行 `ADMIN_BASE=https://admin.nagacoffee.site bash scripts/admin-production-check.sh`。
4. 使用真实店长和店员账号分别验收权限；不得将密码写入脚本、日志或仓库。
5. 在 1366×768、1440×900、1920×1080 浏览器窗口依次检查看板、订单抽屉、商品抽屉、桌码打印预览和营销表单。
6. 演练管理子域名不可用时回退到 `https://nagacoffee.site/#/pages_admin/login/index`。
7. 微信 AppID、商户证书、订阅模板和云打印机型号到位后，在系统状态页确认就绪度并完成真实链路测试。
8. 上传最终商品图片、Logo、经营主体、客服和隐私文本；这些均属于经营方提供的内容资产。
