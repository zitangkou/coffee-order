## 1. 怎么系统梳理 UI 细节（方法论）

### 1.1 先立基线：补齐 Design Tokens

现状：`uni.scss` 只有色板 + 圆角，页面样式大量写在各自 `<style scoped>` 里，导致同类组件尺寸/间距/层级不一致。

补齐规范（写入 `uni.scss` + 公共样式）：

| 维度 | 规范 |
| --- | --- |
| 字号阶梯 | 20 / 22 / 24 / 26 / 28 / 30 / 32 / 36 / 40 / 48 |
| 间距阶梯 | 4 / 8 / 12 / 16 / 24 / 32 |
| 控件高度 | 主按钮 88rpx、输入框 88rpx、筛选胶囊 64rpx、列表项 ≥96rpx |
| 圆角 | 标签 8px、卡片 16px、胶囊 24px、弹层顶部 24px |
| 阴影/描边 | 卡片 `0 2px 8px rgba(0,0,0,.04)`、描边 `#E8E2DB` |
| 状态 | 默认 / 按下 / 禁用 / 加载 / 空态 / 错误，全部有定义 |

### 1.2 逐页走查清单

按「页面 × 维度」交叉检查，产出《UI 走查报告》：

- 页面：顾客端 7 页（首页/详情/购物车/确认订单/支付结果/订单列表/订单详情/咖啡档案）+ 商家端 7 页
- 维度：布局对齐、间距层级、字号层级、点击热区、状态完整（空/加载/错误/禁用）、安全区、超小屏适配、动效克制
- 每条问题标注：P0 明显不协调 / P1 细节瑕疵 / P2 一致性收尾

### 1.3 走查手段

1. **浏览器控制走查**（会话内可执行）：用应用内浏览器打开本地/线上页面，手机视口逐页截图、检查布局
2. **微信开发者工具**：小程序端真机预览
3. **真机**：最后过一遍真实手感

### 1.4 公共组件收敛

同类交互收敛为公共组件，杜绝各页面各自为政：

- `CategoryFilter`：分类筛选（快捷 Tab + 抽屉）
- `Sheet`：底部弹层（规格/选桌/分类共用外壳）
- `FilterChip`：胶囊筛选项
- `ProductCard`：商品卡（首页/菜单共用）
- `AppButton` / `Badge` / `EmptyState` / `StepBar`（已有）/ `SpecSheet`（已有）

## 3. 首页分类筛选器重设计（已实施 · 2026-08-17）

现状问题（旧版）：真实分类全部藏在「当前分类 ▾」抽屉里，主路径「按分类找商品」需要 2 次点击；「全部」视图平铺无分组；分类条不吸顶，滚动中无法切换分类。

**采用方案：吸顶分类条 + 锚点联动**（对比过美团/瑞幸式左右分栏，为保留大图双列的精品店视觉而选择此方案）：

- 分类条吸顶（`position: sticky; top: 0`），横向滚动，直接露出全部胶囊：`全部 / 招牌 n / 热销 n / 各分类名 + 商品数`（无商品的分类不显示）
- 商品区按分区渲染：招牌推荐 → 热销榜单 → 各分类，每区带标题（品牌色竖条 + 名称 + N款）
- 点击胶囊 → `uni.pageScrollTo` 锚点滚动到对应分区；滚动列表 → scrollspy 反向高亮胶囊（60ms 节流，点击后 600ms 锁定期防闪烁）
- 选中胶囊随 `scroll-into-view` 自动滚入可视区
- 售罄商品：置底 + `opacity: 0.55` 灰显（保留原位售罄标签）
- 原分类抽屉整体移除（分类已全部露出，抽屉冗余）

规范：胶囊高约 64rpx、字号 26rpx、圆角 32px；选中 `#2F2A26` 白字，未选白底 `#E8E2DB` 描边；吸顶条背景 `#F7F4F0` 与页面同色、轻投影分隔。

## 4. 商家端分类管理功能（规划）

### 4.1 目标

商家可视化维护分类：新增、改名、启停、**调整顺序**，顾客端菜单自动按新顺序生效。

### 4.2 现状

- 后端：`Category.sortOrder` 字段、分类 CRUD 接口（含 sortOrder 更新）、删除时商品数 >0 禁止删除——**均已具备**
- 顾客端：菜单按 `sortOrder` 升序返回——已生效
- 缺口：商家端没有分类管理页面（分类目前只能在商品编辑时选择）

### 4.3 功能设计

- 新页面 `pages_admin/categories/index.vue`，入口：经营看板新增「分类管理」卡片 + 商品管理页内 Tab
- 列表项：分类名 + 商品数 + 启用开关 + 操作（上移 / 下移 / 编辑 / 删除）
- 排序交互：**上移/下移按钮**（移动端可靠、实现简单），后端交换相邻 sortOrder；序号输入作为备选
- 新增/编辑：名称 + 排序位置；可选分类图标/emoji（视觉增强，建议 P1 加）
- 删除：有商品的分类禁止删除（后端已校验，前端置灰提示）

### 4.4 顾客端

无需改动；若后续加分类图标，卡片上展示图标。
